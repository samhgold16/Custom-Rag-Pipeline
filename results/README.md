# Results

Evaluation reports generated by `uv run rag eval`. Each run writes two files:

* `<date>-<dataset>.md`: summary table, per-question matrix, highlighted questions, and every
  answer with its retrieved sources.
* `<date>-<dataset>.json`: the same data, machine-readable (configs, summaries, per-item
  results, environment).

Every report records the environment that produced it: timestamp, git commit, Ollama version,
model names **and digests**, chunking, temperature, Python and package versions, and a hash of
the dataset. Numbers are never edited by hand; to update them, re-run the command.

`baseline-2026-10-02.md` is the original pipeline's answers to the 12 benchmark questions,
recorded before this rebuild (graded by hand against the letters; no sources were logged then).

Metric definitions and caveats: [`docs/evaluation.md`](../docs/evaluation.md).
